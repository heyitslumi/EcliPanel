# EcliPanel Docs (Standalone Project)

This is a separate documentation project for EcliPanel.

## Run locally

```bash
cd docs
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Main routes

- `/docs/eclipanel` — self-hosting and deployment guide
- `/docs/wings` — patched Wings lifecycle and deployment guide
- `/docs/environment` — backend/frontend `.env` variable reference
- `/docs/ecli` — alias to EcliPanel guide
